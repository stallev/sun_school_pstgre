# P29 — замер на dev-стенде (2026-11-14)

**Стенд:** https://dev-sun-school-pstgre.vercel.app/ (роль admin) · **Метод:** [`P29_phase_description.md`](../implementation/mvp/phases_tasks_descriptions/P29_phase_description.md) § Метод замера — HTML страницы `fetch` с сессией → `iframe srcdoc`; Suspense-блоки подставлены вручную (скрипты Next в `srcdoc` не выполняются). Состояния после гидратации не проверялись. Ширины 360 / 768 / 1024 / 1280 / 1440 / 2560.

## Не удалось проверить (данные или окружение)

- `/audit`: в журнале нет записей (таблицы нет) — D-22 (доли колонок, без скролла на `xl`) и «Техническая запись» не проверены.
- `/year`: нет активного года (есть только «Создать следующий год») — D-06, U-04, диалог закрытия года не проверены.
- Проверка ДЗ: шкала «Тест 0–8» скрыта у этого урока (размер 0) — перенос в 2 ряда и кнопки ≥ 36 px не проверены; длинное имя (≥ 35 знаков) не проверено.
- `/rating`, `/approvals`, карточки достижений: на стенде нет данных или структура без `data-slot=card` — D-32, D-26, D-36 не проверены.
- `/users`, `/people`: счётчик «?» по `aria-label` вернул 0 — подсказки на стенде, вероятно, имеют другую разметку; U-05, U-06 не проверены.
- Состояния после гидратации (меню, диалоги, cookie-переключатель сайдбара) — ручной smoke.
