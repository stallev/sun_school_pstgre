## 1. Purpose

Экраны волны 2 и правило сверки с прототипом. Читают: исполнитель UI-CU P13. Данные и отказы — в контракте. UI-CU начинается только после набора dev-данных (фаза, CU сида).

## 2. Scope / Out of scope

**В scope:** страница семьи admin, успехи ребёнка, данные и согласия, экран согласия, календарь родителя на существующем маршруте, блок контактов на карточке ученика, блок дайджеста. Всё это видно только при `features.parents = true`.  
**Вне scope:** `/verse`, `/verse/debts`, `/verse/debts/[lessonId]`; блок истории голосовых попыток внутри `vChild`; письма; медицинские поля.

## 3. Files / area touchpoints

| Поверхность | Маршрут | Функция прототипа | Роль |
|-------------|---------|-------------------|------|
| Семья | `/family` | `vFamily` | admin |
| Успехи ребёнка | `/child` | `vChild` без блока голоса | parent |
| Данные и согласия | `/child/data` | `vChildData` | parent |
| Согласие | `/child/consent` | `vChildConsent` | parent |
| Календарь | `/calendar` | календарь прототипа, события групп своих детей | parent, чтение |
| Контакты семьи | карточка ученика | блок взрослых: ФИО, тип, телефоны | teacher своей группы, admin |
| Дайджест | секция на `/child` | тексты «достижение», «штраф», «тетрадь принята» | parent |

Перенос маршрутов из §5 в §4 [`canonical_routes.md`](../../../design/canonical_routes.md) — задача P13, когда страницы есть. До этого они остаются референсом. Пункты меню parent появляются только при включённом флаге: успехи, календарь, данные и согласия. «Согласие» — не пункт меню, а экран-шлюз.

Словарь: срез `parent` (ru, en) и ключи `admin.family.*`. Подписи секций, совпадающие с прототипом, не дублируются строками в JSX.

## 4. Визуальный эталон

Обязательная сверка с прототипом и правилами **ui-prototype-fidelity** / **ui-design-system-shadcn**: токены Slate Cobalt, каталог Design Lab, без ad-hoc hex.

На ширинах **390 px**, **`md`**, **`lg`**: типографика, отступы, радиусы, порядок блоков, состояния empty / loading / error. Консоль без `error` и `unhandledrejection`. Расхождение чинится на всей странице, не только в новом блоке.

Фразы прототипа про голосовую проверку на `vChild` в этой волне не показываются.

## 5. Состав экранов

### 5.1 `vFamily` (admin)

Название, адрес, примечание. Взрослые: тип, контакты, учётка и её статус, какие согласия дал. Дети: группа, статус согласия и кем дано. Действия: изменить данные, добавить или исключить взрослого и ребёнка, отметить бумажное согласие, перейти в профиль и карточку ученика, последние записи журнала по семье. Пустое состояние — нет семей. Ошибка валидации оставляет форму.

### 5.2 `vChild` (parent)

Только свой ребёнок: посещаемость за год, динамика баллов, достижения и штрафы (если включён `features.achievements`; иначе секции нет), баланс кирпичиков. Без рейтинга и без сравнения с другими детьми. Секция дайджеста текущей недели. Голосовой прогресс скрыт. Нет ребёнка с действующим согласием — пустое состояние, не чужие данные.

### 5.3 `vChildData` и `vChildConsent`

«Данные и согласия»: семья на чтение, правка своих телефона и email, список согласий, отзыв, запрос на удаление и его отмена, открытый запрос другого взрослого. Экран согласия: один ребёнок за раз, флажок по умолчанию снят, без согласия данные ребёнка не показываются.

### 5.4 Календарь и контакты

Parent на `/calendar` видит события групп, куда зачислены его дети, без правки. На карточке ученика учитель видит взрослых (ФИО, тип, телефоны). Адреса и примечания на этой карточке нет.

## 6. Состояния

| Состояние | Где | Поведение |
|-----------|-----|-----------|
| Флаг выключен | все маршруты §3 | 404, пунктов меню нет |
| Нет согласия | `/child` для этого ребёнка | данные скрыты, ведёт на `/child/consent` |
| Чужой ребёнок | parent | 404 |
| Teacher на `/family` или `/child` | флаг включён | «Нет доступа» |
| Нет семей / нет выдач в дайджесте | список | `EmptyState` |
| Ошибка мутации | формы | поле с ошибкой, toast, pending по правилам мутаций |
