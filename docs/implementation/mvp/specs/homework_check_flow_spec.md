## 1. Purpose

Спецификация экранов, на которых учитель вносит и исправляет оценки: **последовательная проверка** и **сводная таблица урока**. Читают: исполнитель P03/P04, `reviewer` (UI, путь S/N), автор тестов.

## 2. Scope / Out of scope

**В scope:** маршруты `/check`, `/lessons/[lessonId]/check`, `/lessons/[lessonId]/table`; режимы проверки и исправления; клавиатура и a11y; связь «поле экрана → поле контракта».  
**Вне scope:** создание и правка урока ([`homework_check_contract.md`](../contracts/homework_check_contract.md) §5.1–§5.3); выдача кирпичиков ([`bricks_ledger_contract.md`](../contracts/bricks_ledger_contract.md), `/bricks`); достижения и штрафы (post-MVP: блоки не показываются); голосовая оценка.

## 3. Definitions

| Термин | Значение |
|--------|----------|
| Roster | ученики с зачислением в группу урока на дату урока; ученик, добавленный позже, — через создание записи (БП-12) |
| Запись | `homework_check` (ученик × урок) |
| Режим «проверка» | урок `HELD`, год `ACTIVE`: `savePartialCheck` / `saveChecked` |
| Режим «исправление» | урок `CHECK_COMPLETED` либо запись `Checked`: `correctCheck` |
| Текущий урок | ближайший по дате урок группы со статусом `HELD` с датой ≤ «сегодня» в поясе школы; если нет — страница выбора урока |

| `/lessons/[lessonId]/check` | Последовательная проверка / исправление | `TEACHER` (своя группа), `ADMIN` по ссылке (Q-04 матрицы) |

## 5. Последовательная проверка

### 5.1 Раскладка

| Ширина | Раскладка |
|--------|-----------|
| ≥ `lg` | Две колонки: слева sticky-список учеников (`aside`, 16 rem), справа карточка ученика; нижняя полоса действий внутри карточки. **Плотная раскладка карточки (P24, §5.2а):** на 1920×1080 карточка обычного урока со стихами, тестом и тетрадью помещается без вертикальной прокрутки страницы |
| < `lg` | Сворачиваемый список («Ученики · N из M»), карточка во всю ширину, **фиксированная нижняя панель** (`inset-x-0 bottom-0`, `safe-area-inset-bottom`): «Предыдущий», «Сохранить и далее» |

Прогресс — полоса «Проверено N из M» (режим «проверка»); в режиме «исправление» прогресса нет, вместо него баннер (§5.4).

### 5.2 Порядок блоков карточки (как в прототипе)

| № | Блок | Элемент | Поле контракта (§4.2) |
|---|------|---------|------------------------|
| 1 | Шапка | ФИО (`h2`), «N из M», год рождения, **итог баллов**, «заполнено K из N» (§5.3) | — (вычисляется для показа клиентом через `computePoints` из `@sunschool/domain`; серверный итог — при сохранении) |
| 2 | Присутствие | компактный `SegmentedControl` «Да / Нет» **по ширине содержимого** (`fit`, кнопки `h-9 px-3`, не растягиваются на ширину карточки; P24) | `present` |
| 3 | Спевка | переключатель; на ≥ `lg` — в одном ряду с присутствием (§5.2а), на < `lg` — отдельный ряд | `singing` |
| 4 | Стихи | плитки 0 / 1 / 2 и тихая «не ставил» (§5.3); свёрнуты при «Не был» без `late` | `verseScores[]` |
| 5 | Тест | крупная цифра и панель 0–10 (§5.3); только если у урока `hasTest` | `testScore` |
| 6 | Тетрадь | крупная цифра и панель 0–10 (§5.3) | `notebookScore` |
| 7 | Комментарий | поле с видимой подписью (необязательно, ≤ 500) | `comment` |
| 8 | Причина (только исправление) | чипы «Сдал позже», «Ошибка ввода», «Другое» | `reason` |
| 9 | Действия | «Предыдущий», «Сохранить и далее» / «Завершить проверку» / «Сохранить исправление» | операции §6 |

На < `lg` присутствие и спевка — отдельные ряды, разделены линией `line`. Под присутствием подпись «Присутствие на баллы не влияет: задания можно сдать позже» (БП-10). Если выбрано «Не был» и запись не `late`, стихи, тест и тетрадь свёрнуты (§5.3).

### 5.2а Плотная раскладка на ≥ `lg` (P24)

Порядок блоков §5.2 и поля контракта не меняются — меняется только сетка карточки.

| Ряд | Содержимое (≥ `lg`) |
|-----|---------------------|
| 1 | Шапка (как §5.2 п. 1) |
| 2 | Присутствие (компактный сегмент) и спевка — **в одну строку** (`flex flex-wrap items-center gap-x-8 gap-y-3`); подпись БП-10 — под рядом, `text-sm text-muted` |
| 3 | Сетка `grid-cols-2 gap-x-8 gap-y-5`: слева «Стихи», справа «Тест» и «Тетрадь» друг под другом. Без `hasTest` — справа только «Тетрадь». Обзорный урок (нет стихов и теста) — одна колонка |
| 4 | Комментарий (на всю ширину карточки, `Textarea` в 2 строки) и причина (режим исправления) |
| 5 | Полоса действий |

Шкала 0–10 на ≥ `lg` — `ScorePad` `layout="inline"`: «—» и 11 кнопок `0…10` **в одну линию** (кнопки `h-9`, `min-w-9`), без открытия панели; выбранное значение — стиль выбранного чипа UX-03 D-10. На < `lg` — как раньше: крупная цифра и панель `layout="keypad"` (§5.3). Свёртка «Не был» (§5.3) скрывает ряд 3 на любой ширине.

### 5.2б Аккордеон «Стихи урока» (P24)

На экранах проверки (`/lessons/[lessonId]/check`) и сводной таблицы (`/lessons/[lessonId]/table`) над рабочей областью (на проверке — под прогрессом и перед сеткой «ученики / карточка»; на таблице — перед полосой фильтров) стоит **компактный аккордеон с текстами стихов этого урока**, чтобы учитель видел, что именно оценивает, не уходя на карточку урока.

| Свойство | Правило |
|----------|---------|
| Состояние | **Свёрнут по умолчанию**; состояние не сохраняется между экранами |
| Заголовок (свёрнутый) | Одна строка `min-h-11` на < `lg` и `min-h-9` на ≥ `lg`: иконка, «Стихи урока N», через `·` — ссылки стихов (`truncate`), шеврон справа. Кнопка на всю ширину (`aria-expanded`, `aria-controls`) |
| Раскрытый | **Липкий**: закрепляется под шапкой оболочки (`sticky top-14 z-30`), пока открыт, чтобы тексты стихов оставались на виду при прокрутке карточек и строк; свёрнутый — обычный блок потока. Высота списка ограничена (`max-h-[min(45dvh,22rem)]`, внутренняя прокрутка), чтобы не закрывать рабочую область. Список `ol`: ссылка на стих (`font-medium`) и текст курсивом `font-display text-base`, плотно (`space-y-2`); отсутствие текста — `AlertText` «Текст стиха недоступен» (как на карточке урока) |
| Когда нет | Обзорный урок и урок без стихов — аккордеон не рендерится |
| Данные | Тексты выбирает сервер (`loadLessonVerseTexts`, перевод по языку группы); доступ — тот же, что у экрана, чужой урок → `NOT_FOUND` до загрузки текстов |
| Доступность | Нативная кнопка, `Enter`/`Space` переключают; шеврон поворачивается 150 мс, при `prefers-reduced-motion` без анимации; фокус остаётся на кнопке |

### 5.2в Лидер урока (P24, UX-03 D-16)

Ученик с **наибольшим итогом за урок** подсвечивается золотым фоном (`bg-gold-soft`) на проверке, сводной таблице и ведомости (§7.4).

| Правило | Значение |
|---------|----------|
| Кто участвует | Записи с `homeworkChecked = true`, итог > 0 (на таблице — показанный итог строки, §7.1) |
| Ничья | Подсвечиваются **все** ученики с максимальным итогом |
| Нет участников | Нет проверенных или у всех 0 — подсветки нет |
| Вид | Фон `gold-soft`, левая граница `border-l-4 border-gold`, иконка `Trophy` (`text-gold-ink`, `aria-hidden`) и `sr-only` «Лучший результат урока»; цвет не единственный признак. Внутри золотой строки цвета статуса (`ok`, `danger`, `muted`) **не используются** (контраст на `gold-soft` 4.2–4.4 < 4.5): оценки `ink`, пустые значения и номер `ink-2` |
| Проверка (список учеников) | Золотой элемент списка; **активный** лидер остаётся выделенным кольцом `ring-2 ring-inset ring-cobalt-ink` (кобальтовое выделение активного не теряется) |
| Сводная таблица | Золотая строка (в том числе липкие ячейки «Ученик» и «Итого») и карточка ученика < `md` |
| Пересчёт | Обновляется после сохранения; для ещё не проверенных учеников не считается |
| Данные | Выбор — чистая функция по уже загруженным итогам; БД, мутации и права не меняются |

### 5.3 Элемент оценки (`score row`)

Сохранение по-прежнему только кнопкой «Сохранить и далее» / «Сохранить исправление». Цифра в панели пишет локальную форму и закрывает панель; `savePartialCheck` на этом экране не вызывается (§5.5).

| Аспект | Правило |
|--------|---------|
| Стих | `role="radiogroup"`: плитки **0 / 1 / 2** и отдельная тихая «не ставил» (`NULL`, `aria-label` «Не оценивалось»). Кнопки — `role="radio"`, `aria-checked`. ←/→ меняют значение |
| Тест и тетрадь | < `lg`: в покое — крупная цифра или «—» и подпись полосы принятой шкалы: до 4, от 8, средний пояс между ними; нажатие открывает `ScorePad` `layout="keypad"`, выбор пишет локальную форму и закрывает панель. ≥ `lg`: inline-ряд «— 0 … 10» без панели (§5.2а), `role="radiogroup"`, ←/→ меняют значение; подпись полосы шкалы остаётся |
| Свёртка | «Не был» и запись не `late`: стихи, тест и тетрадь скрыты, кнопка «Показать оценки». Значения в состоянии **не очищаются**; повторный «Был» снова показывает рубрику. При `late` рубрика открыта — поздняя сдача учитывается при отсутствии |
| Комментарий | видимая подпись, не только placeholder |
| Счётчик | в шапке «заполнено K из N» по обязательным полям этого урока: присутствие, стихи (если есть), тест (если `hasTest`), тетрадь. Спевка и комментарий не входят: у спевки всегда есть значение |
| Список учеников | к иконке слово «проверен» / «не проверен». «Частично» — запись не проверена, но уже есть хотя бы одна оценка |
| Повторный выбор | выбор уже выбранного значения не снимает его; снять — «не ставил» / «Не оценивалось» |
| Метка «сдано <дата>» | если оценка выставлена позже даты следующего урока (`late`), цвет `amber-ink` **+ текст** (не только цвет) |
| Клавиатура | ←/→ внутри радиогруппы стиха меняет значение (APG). Escape закрывает панель 0–10 без записи незавершённого ввода |

### 5.4 Режимы

| Режим | Условие | Отличия |
|-------|---------|---------|
| Проверка | урок `HELD`, запись не `Checked` | прогресс, «Сохранить и далее», на последнем непроверенном — «Завершить проверку» (§6) |
| Исправление | урок `CHECK_COMPLETED` или запись `Checked` | баннер «Урок уже проверен. Изменения пересчитают баллы и кирпичики и попадут в журнал; новые оценки получат отметку «сдано <дата>». Присутствие задним числом не меняйте.» (`warn-soft`, иконка + текст); блок причины; кнопка «Сохранить исправление»; «Следующий» вместо автоперехода |
| Обзорный урок | `kind = REVIEW` | нет блока стихов и теста; подпись «Обзорный урок: тетрадь и спевка»; показывается тетрадь и спевка |
| Закрытый год (teacher) | год `CLOSED` | форма **не рендерится**; баннер D3 «Год закрыт — только чтение»; таблица доступна только для просмотра |
| Закрытый год (admin) | год `CLOSED` | форма доступна; причина **обязательна** |

### 5.5 Поток действий

1. Вход на экран: открыт первый непроверенный ученик (в режиме «проверка») либо ученик из параметра (`?pupil=`) / строки таблицы.
2. Учитель вводит оценки → **локальное состояние формы**; индикатор «Есть несохранённые изменения» (D14). Ошибка «Отметьте присутствие перед сохранением» у блока «Присутствие» **сбрасывается сразу при выборе** «Да» или «Нет» и **при смене текущего ученика** (выбор в списке, «Предыдущий», «Следующий», переход после сохранения): ошибка принадлежит ученику, а не экрану (P24).
3. «Сохранить и далее»: всегда `saveChecked` (завершает запись ученика; присутствие обязательно). Результат: toast «Сохранено: <ФИО>», фокус на следующего ученика. `savePartialCheck` на этом экране не вызывается (только сводная таблица, §7.2).
4. Последний ученик: «Завершить проверку» → `saveChecked` для него, затем `completeLessonCheck` (явная кнопка, решено 2026-10-11); показывается экран §5.6.
5. Смена ученика (выбор в списке, «Предыдущий», «Следующий», ←/→) при несохранённых изменениях открывает **модальный диалог** (`ConfirmDialog` на базе `Dialog`, не `window.confirm`; UX-06 §7.2):
   - заголовок «Есть несохранённые изменения», текст «Сохранить оценки ученика <ФИО> перед переходом?»;
   - «Сохранить и перейти» (primary) — `saveChecked` (или `correctCheck` в режиме исправления) по текущему ученику; при успехе — переход к выбранному и фокус на его `h2` (§5.7); при ошибке (`VALIDATION`, в том числе нет присутствия) — диалог закрывается, перехода нет, ошибка у поля. Инвариант: после успешного «Сохранить и перейти» диалог закрывается первым, и фокус на `h2` выбранного ученика ставится уже после закрытия — через `finalFocus` на этот заголовок либо после завершения закрытия (`onOpenChangeComplete`); Base UI при закрытии возвращает фокус на trigger, и перенос фокуса, сделанный пока диалог ещё открыт, этим возвратом затирается.
   - «Не сохранять» (outline) — локальные изменения текущего ученика отбрасываются, переход к выбранному, toast «Изменения сброшены» (2000 мс);
   - «Остаться» (ghost), Escape, клик по фону — диалог закрывается, ученик и введённое не меняются, фокус возвращается на элемент, вызвавший переход.
   Фокус при открытии — на «Сохранить и перейти». Пока идёт сохранение — кнопки `disabled`, `aria-busy`, подпись «Сохраняем…».
6. Выход со страницы с несохранёнными изменениями: клиентская навигация (пункт меню, ссылка) — тот же диалог п. 5 с действием «перейти» вместо «к ученику»; перезагрузка и закрытие вкладки — `beforeunload` браузера (текст задаёт браузер; UX-06 §7.2).
7. Автосохранения нет: ни переход, ни Enter на кнопке сегмента не вызывают `saveChecked` без явного действия «Сохранить и далее» / «Сохранить и перейти» (P24, §5.7).

### 5.6 Экран «Проверка завершена»

| Элемент | Содержание |
|---------|------------|
| Заголовок | «Проверка завершена», «Урок N · <тема> · все M учеников» |
| Итог | «Проверено M из M»; ссылка «Сводная таблица»; «К выдаче кирпичиков» (→ `/bricks`) |
| Не показывается в MVP | блок «Кого отметить в воскресенье» и пересчёт достижений (post-MVP, прототип показывает при включённом режиме) |

### 5.7 Клавиатура

| Клавиша | Действие |
|---------|----------|
| Enter (фокус не в текстовом поле и **не на кнопке** — сегменте, плитке, чипе, кнопке шкалы, ссылке) | сохранить (как главная кнопка). Если фокус на кнопке, Enter активирует **только её** (нативное поведение), глобальный обработчик сохранения не срабатывает (P24: устраняет «самосохранение» после выбора присутствия) |
| ← / → (вне радиогруппы) | предыдущий / следующий ученик |
| ← / → (в радиогруппе) | изменить значение |
| Esc | закрыть раскрытый текст стиха, панель 0–10 или диалог |

Подсказка «Enter — сохранить · ← → — ученики» видна на `xl` и в `aria-describedby` кнопки; фокус после сохранения — на заголовок следующего ученика (`h2`, `tabindex="-1"`), результат объявляется `aria-live="polite"`.

## 6. Операции и контракт

| Действие UI | Операция контракта | Код отказа → поведение |
|-------------|--------------------|------------------------|
| «Сохранить и далее» / «Завершить» по ученику (последовательная проверка) | `saveChecked` | `VALIDATION` (`fields.present`, `fields.*`) → ошибка у поля, фокус; `CONFLICT` → «Запись изменилась» + «Загрузить актуальное»; `CHECK_YEAR_NOT_ACTIVE`, `FORBIDDEN` → баннер D3 |
| «Завершить проверку» | `saveChecked` + `completeLessonCheck` | `CHECK_NOTHING_CHECKED` → сообщение «Проверьте хотя бы одного ученика» |
| «Сохранить исправление» | `correctCheck` | `CHECK_NO_CHANGES` → toast «Изменений нет» (без записи); `VALIDATION` (`fields.reason`) для admin в закрытом году |
| Ручная оценка стиха из голоса | — (post-MVP) | в MVP источника `VOICE` нет |

Значения `late`, `pointsTotal`, `checkedBy`, время — серверные; клиент их **не отправляет**. `expectedUpdatedAt` берётся из загруженной записи и отправляется с каждой мутацией (TX-3).

## 7. Сводная таблица урока

### 7.1 Состав

P10-CU9 зафиксировал `<select>` на этом экране; **P11 — тихая ячейка и панель** (`ScorePad`). Последовательная проверка — свой контракт контролов (§5.3): там сохранение только кнопкой карточки, здесь — сразу по ячейке.

| Элемент | Правило |
|---------|---------|
| Стихи | Аккордеон «Стихи урока N» по §5.2б — после заголовка и прогресса, перед фильтрами |
| Заголовок | Номер и тема урока один раз, дата (день и месяц, локаль UI). Линейный прогресс как на проверке. Числа по **всем** строкам, не по отфильтрованным: были, не проверены, проверено. Строки среднего балла нет (аналитика). Кнопка «Последовательная проверка» — единственная primary |
| Фильтры | Чипы «Все», «Непроверенные», «Были»; полоса **липнет** под шапкой. «Все» сбрасывает фильтры. «Непроверенные» и «Были» можно включить вместе. Пока урок не `CHECK_COMPLETED` и проверены не все, «Непроверенные» включён по умолчанию |
| Столбцы (≥ `md`) | №, Ученик (ссылка → `/check?pupil=`), Был, группы «Память» (стихи, шкала 0–2 в заголовке), «Работа» (тест, если `hasTest`, тетрадь 0–10, спевка), «Итог». Колонки «Открыть» нет. Имя и итог липкие. «Итого» — `NumberDisplay` |
| Статус строки | Слово у имени: «не проверен» или «не был», плюс узкая текстовая метка. Сплошной заливки строки нет |
| < `md` | **карточка-стек**: имя, итог, те же тихие ячейки, кнопки присутствия и спевки ≥ 44 px |
| Значения | **нет** `select`. Стих, тест и тетрадь в покое — цифра или «—». «Итого» — «—», пока нет ни одной введённой оценки (стих / тест / тетрадь, включая явный `0`, или включённая спевка); иначе клиент показывает `computePoints` из текущих полей строки (присутствие на баллы не влияет). После завершения проверки ученика — сохранённый серверный `pointsTotal` |
| NULL vs 0 | «—» и «Не оценивалось» = `NULL`; выбранный `0` = 0 (INV-11, R-1). «—» **не** является нулём |
| Раскраска | `ok` от 8, `danger` до 4 (тест, тетрадь) — **плюс** значение; в покое цвет ячейки **не меняется** из‑за открытия панели |
| Метка «позже» | один бейдж «позже» у имени, не под каждой оценкой |
| Сортировка | по ФИО; других нет в MVP |
| Таблица | `<table>` с `<th scope="col">`, горизонтальная прокрутка внутри карточки |

### 7.2 Редактирование в таблице

Мутации, DAL и domain **не меняются**: та же ячейка вызывает `savePartialCheck` (запись не завершена) либо `correctCheck` (запись проверена; причина по умолчанию не требуется, для admin в закрытом году — диалог причины).

**Стих, тест и тетрадь.** В покое ячейка показывает цифру или «—». Нажатие открывает **одну** панель. Стих (0–2): `ScorePad` `layout="inline"`, кнопки `—  0  1  2`. Тест и тетрадь (0–10): `ScorePad` `layout="keypad"` — на всю ширину «Не оценивалось» (ключ `check.score_not_rated`), затем сетка `0…5` / `6…10`. Выбор **сразу сохраняет** и закрывает панель. «—» = `NULL`.

- ≥ `md`: панель — popover **под** ячейкой (`@base-ui/react/popover`). Предпочтительная сторона `bottom`; нет места снизу — `collisionAvoidance.side = "flip"` (вверх).
- < `md`: та же панель **разворачивается под полем** в карточке; имя ученика остаётся на экране.
- Одновременно открыта **только одна** панель. Повторное нажатие по ячейке, клик снаружи, Escape — закрытие **без** сохранения.
- После касания фокус **не прыгает** на другую ячейку. Tab — к следующему полю **в той же строке**.
- Пока запрос в полёте: оптимистичное значение + `aria-busy`. Ошибка: `toast.error` + откат (`ui-optimistic-mutations`). **Success toast на каждую оценку не показываем.**
- «Был» и «Спевка» на `md+` — кнопки `aria-pressed`, как на карточках, не нативный checkbox. Те же правила мутации.
- Параллельная правка (`CONFLICT`) — ячейка откатывается, строка подсвечивается, «Запись изменилась — обновите».

**Клавиатура панели** — §7.3 (для стиха 0–2 цифры вне 0–2 не отправляются; `1`+`0` = 10 только у шкалы 0–10).

### 7.3 Клавиатура панели (только сводная таблица)

Клавиатура последовательной проверки — §5.7.

| Клавиша | Действие |
|---------|----------|
| Цифры `0`–`9` | выставить оценку; `1` затем `0` = 10 |
| Backspace | вернуть «—» (`NULL`), не 0 |
| Tab | следующее поле в той же строке |
| Escape | закрыть панель без сохранения |
| Повторное нажатие / клик снаружи | закрыть панель без сохранения |

Клиент **не отправляет** значение вне 0–10 и неполный ввод кроме завершённой пары `1`+`0`.

### 7.4 Ведомость урока (P24)

Кнопка **«Ведомость»** (`outline`, иконки `FileSpreadsheet` и `ExternalLink`, `aria-label` «Ведомость урока (откроется в новой вкладке)») в шапке `/lessons/[lessonId]/check` и `/lessons/[lessonId]/table` открывает **в новой вкладке** маршрут `/lessons/[lessonId]/sheet` (`<a target="_blank" rel="noopener noreferrer">`). Это read-only обзор результатов урока по каждому ученику, готовый к показу на экране и печати.

| Свойство | Правило |
|----------|---------|
| Оболочка | **Без** оболочки приложения (нет сайдбара и шапки навигации); вся ширина окна под таблицу. Отдельная группа маршрутов `(sheet)` с тем же входом по сессии |
| Доступ | Как у сводной таблицы (AZ-читатель урока): admin; teacher своей группы; закрытый год — только чтение; чужой урок → `NOT_FOUND` |
| Шапка | Одна строка: «Ведомость · Урок N · тема · дата»; счётчики «были X из N · проверено Y»; лидер «Лучший результат: имена — N б.» (§5.2в); кнопки «Печать» и «К проверке» |
| Колонки | №, Ученик, Был (✓ / —), по колонке на стих (С1…Сn, шкала 0–2), Тест (если `hasTest`), Тетрадь, Спевка (✓ / —), **Итого**. Обзорный урок — без стихов и теста. «Сдано позже» — метка `*` рядом с ФИО (признак записи `late`, `amber-ink`, `aria-label` «сдано позже»). Пустое значение — «—» |
| Строки | Все ученики состава урока по ФИО, включая «добавлен позже»; непроверенные — тихий «не проверен». Строки среднего балла нет (аналитика, §7.1) |
| Лидер | Золотая строка по §5.2в, легенда под шапкой |
| Компактность | Таблица `text-sm`, плотные строки; на ≥ 1024 px **целиком на одном экране без прокрутки** при ≤ ~30 учеников: высота строки `clamp(1.5rem, (100dvh − шапка) / число строк, 2.5rem)`, ширина колонок фиксирована (`table-fixed`), горизонтальной прокрутки нет. При большем составе — минимальная высота строки и обычная прокрутка страницы; шапка таблицы липкая |
| Печать | `@media print`: без кнопок, альбомная ориентация, цвета сохраняются, строки не разрываются |
| Состояния | Нет учеников — `EmptyState`; урок не найден — 404; загрузка — скелетон таблицы |
| Доступность | Единственный `h1`; `<table>` с `<th scope>`; «Печать» — `<button>`; `lang` корневой |

## 10. Negative paths

| Случай | Исход |
|--------|-------|
| Присутствие не отмечено при итоговом сохранении | Ошибка у блока «Присутствие», фокус на нём, не сохранено. Выбор «Да» / «Нет» сразу убирает ошибку; у следующего ученика ошибки нет, пока он сам не попытается сохраниться без присутствия (P24) |
| Enter при фокусе на кнопке сегмента «Да / Нет» или плитке | активируется только эта кнопка; сохранения нет (P24) |
| Смена ученика с несохранёнными изменениями, «Остаться» / Escape | ученик и форма не меняются, запросов нет (P24) |
| «Сохранить и перейти» без присутствия | диалог закрывается, ошибка у «Присутствия», перехода нет (P24) |
| Две вкладки / два учителя правят одного ученика | `CONFLICT`: «Запись изменилась», «Загрузить актуальное», локальные значения сохраняются для переноса |

| Backspace в панели 0–10 | ячейка «—» (`NULL`); `0` сохраняется только явной кнопкой «0» |
| Пустая запись / «Не оценивалось» | `NULL`; пустая строка и omitted-поле не подменяются нулём |

| Попытка открыть чужой урок | 404 |

## 14. Acceptance criteria

- [ ] Порядок блоков и подписи совпадают с §5.2 — исход: сверка с экраном.

## 17. Agent notes

- Не вычислять и не отправлять `late`, итог записи, автора и время.
- Не превращать «не оценивалось» в 0; не отправлять пустую строку.
- Не показывать блок достижений и штрафов в MVP.
- Не менять присутствие автоматически при поздней сдаче.
- Не рендерить форму teacher в закрытом году, проверка на сервере остаётся.
- Не возвращать `select` оценок и колонку «Открыть»; не подменять `NULL` нулём.
- Не вызывать `savePartialCheck` с карточки проверки: цифра там только локальная форма.
- Не очищать оценки при «Не был» и не сворачивать рубрику, если запись `late`.
- Не показывать success toast на каждую оценку в таблице.
- Не добавлять строку среднего балла в журнал.
- Не использовать `window.confirm` для несохранённых изменений (P24, R-13).
- Не держать ошибку присутствия одним состоянием на экран без сброса (P24, R-11).
- Не вешать глобальный Enter без проверки цели события (P24, R-12).
