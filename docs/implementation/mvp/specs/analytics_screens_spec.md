## 1. Purpose

Спецификация экранов **аналитики группы**, **ученика** и **сводки школы**: фильтры периода, KPI, состав выборки (БП-1), четыре групповых графика с одной осью Y, таблицы, блок «кто какие уроки провёл», динамика успеваемости (9.1.3), пояснение методологии (9.6). С v1.2 — **аналитика по учебным годам**: полоса лет, итоги по годам, разница с прошлым годом, закрытый год в режиме чтения, история ученика по годам (§5.5–§5.6, §6.5, §7.1). Читают: P05-CU4…CU8, P08, `reviewer`, автор тестов DAL.

## 2. Scope / Out of scope

**В scope:** маршруты `/analytics`, `/analytics/pupils/[pupilId]`, блоки аналитики на `/school` (admin); read-only UI; фильтры год / месяц / диапазон; переключатель группы (admin); строка качества данных (admin); табличная альтернатива графикам (a11y); **(v1.2)** выбор учебного года на этих экранах, итоги по годам, разница с прошлым годом, итоги активного года и ссылка «Все годы» на `/group`.  
**Вне scope:** родительский кабинет и `/child` (post-MVP); метрики голосовой проверки, достижений, штрафов (9.3–9.4, post-MVP — блоки не рендерятся); рейтинг (`/rating` — [`P05_phase_description.md`](../phases_tasks_descriptions/P05_phase_description.md)); экспорт/печать; режим «сравнить два выбранных года» (не делаем: только разница с прошлым годом, PRD §4); поимённые таблицы закрытых лет из снимков (они считаются по записям года, §5.5).

## 3. Definitions

| Термин | Значение |
|--------|----------|
| Проверенный урок | урок с ≥1 записью `homework_check` в статусе проверено (БП-1) |
| Слой A / B / C / D | основная выборка; активен, явка &lt;50%; неактивен; активен без проверенных уроков после зачисления (БП-1) |
| Наблюдение | валидная точка для метрики (БП-2…БП-4, 9.1.3) |
| Нормированный балл | баллы урока / максимум урока × 100 (9.1.3) |
| Снимок года | зафиксированные при закрытии годовые итоги группы / ученика — [`analytics_year_snapshots_contract.md`](../contracts/analytics_year_snapshots_contract.md) §3–§4 |
| Год по умолчанию | активный → последний закрытый → «нет лет» (контракт §6.5) |
| N / M | пороги достоверности: детей / проверенных уроков (контракт §5; сейчас 10 / 4) |
| Разница | значение показателя минус значение ближайшего прошлого года из доступных; явка — п. п. (контракт §6.6) |

Формулы средних, посещаемости, динамики — **`packages/domain/src/analytics/*`** (P05-CU4), не в UI.

## 5. Экран «Аналитика группы» (`/analytics`)

### 5.1 KPI и состав выборки

| Блок | Содержание | Правило |
|------|------------|---------|
| Главная цифра | средняя явка слоя A, % | одна цифра `NumberDisplay`; подпись — число детей в A |
| Компактный ряд | средние стихи / тест / тетрадь по A с **N** наблюдений | БП-2…БП-4; проценты и средние — 1–2 знака |
| Состав | «основная A · реже 50% B · неактивные C · без уроков D» | счётчики, не карточки |
| Пометка удаления (admin) | баннер без раскрытия числа детей &lt;3 | спец. 9.1, УД-7; ключ `analytics.deletion_recalculated` |
| Качество данных (admin) | пропущенные записи на проверенных уроках; дубли миграции | `DataQualityNote`; не ошибка ученика |

### 5.2 Графики (основная выборка, одна ось Y каждый)

Четыре отдельных графика (9.5), ось X — даты уроков:

1. **Посещаемость** — доля присутствующих от A на урок, %; в подсказке — число детей.
2. **Стихи** — среднее число рассказанных стихов за урок (БП-2); первый обычный урок года без точки; обзорные без точки.
3. **Тест** — средний балл 0–10 (БП-3); обзорный урок — без точки; в подсказке «не проводился» если `hasTest=false`.
4. **Тетрадь** — средний балл 0–10 (БП-4).

Под каждым графиком — одна строка «как считали» (ссылка на §8 / раскрытие `MethodologyNote`). У каждого графика — **`ChartTableToggle`**: таблица дата / значение / N (a11y). Цвет не единственный носитель смысла: значение в подсказке и таблице.

### 5.3 Таблицы учеников

| Таблица | Колонки (минимум) |
|---------|-------------------|
| Основная выборка (A) | ФИО (→ `/analytics/pupils/[id]`), год рождения, явка %, был/проверено, средние стихи/тест/тетрадь |
| Исключённые (B) | ФИО, год рождения, был, проверено уроков, явка % |
| Неактивные (C) | ФИО, год рождения |
| Без проверенных уроков (D) | ФИО, в группе с (дата зачисления) |
| По году рождения | описательно, только A; оговорка о малой выборке |

Пустые секции B/C/D — текст «Таких учеников нет» (`analytics.tables.empty_section`), не скрывать заголовок.

### 5.4 Блок «Кто какие уроки провёл» (9.1.4)

Таблица: учитель; провёл (проверенные уроки периода); обычных / обзорных; запланировано; ссылки на уроки. Учитель вне назначения — пометка «уже не в группе». Родителю блок **не** показывается (в MVP родительский маршрут отсутствует). Подзаголовок: ведущий ≠ проверяющий.

### 5.5 Полоса лет, итоги по годам, закрытый год (v1.2)

Порядок блоков: заголовок → переключатель группы (admin) → **полоса лет** → **таблица «Итоги по годам»** → (закрытый год) пометки → переключатель периода → одна сводка периода → графики → таблицы → блок учителей (только активный год).

| Блок | Содержание | Правило |
|------|------------|---------|
| Полоса лет (`YearStrip`) | кнопки доступных лет, активный помечен «идёт»; выбранная кнопка как чип периода: заливка `ink`, текст `surface`; `role="radiogroup"`, `aria-checked` | годы по видимости (контракт §7): teacher — годы назначения, admin — все со снимком; выбор пишет `?year=`; отклик — §5.7 |
| Таблица итогов (`YearTotalsTable`) | год · детей в основной выборке · уроков проверено · явка · стихи · тест · тетрадь; под каждой цифрой — разница (`DiffBadge`); строка открывает год; метка «закрыт / идёт» и «методология vX», если ≠ текущей | закрытые годы — из снимков, активный — вживую; `<caption class="sr-only">`; ось «годы», не уроки |
| Пояснение | «В разные годы в группе могли быть разные дети: это сравнение составов, а не одних и тех же учеников» | `analytics.years.composition_note` |
| Закрытый год | `ReadOnlyYearNote` («Закрытый год — только чтение. Итоги зафиксированы при закрытии года»); при `methodology_version` ≠ текущей — `MethodologyVersionNote` | KPI и таблица итогов — из снимка; **графики по урокам и поимённые таблицы (A / B) считаются по записям выбранного года** теми же функциями, что для активного; «качество данных» и «кто какие уроки провёл» — только активный год |
| Сводка периода | «Средняя явка основной выборки», стихи, тест, тетрадь выбранного периода, с N и «детей с явкой от 50%» | один блок на `/analytics` (`AnalyticsPeriodKpiSection`). Четыре плитки `KpiTiles` на этой странице не рисуются: те же цифры года уже в строке таблицы, разница — в `DiffBadge`. `KpiTiles` остаётся на `/group` |

**Разница (`DiffBadge`):** «на 6 п. п. выше» / «на 0,4 ниже» / «как в прошлом году»; стрелка вверх/вниз дублирует слова, цвет не носитель смысла; при `kids < N` или `lessons < M` в любом из двух лет — «мало данных для сравнения» (INV-27). Прошлый год — ближайший более ранний **из видимых**.

**Год по умолчанию:** активный; иначе последний закрытый; «нет лет» — заглушка «учебный год не начался». После закрытия года и до активации следующего экраны **не пустеют**: открывается только что закрытый год.

**Сверка с прототипом:** `yearChips` → `YearStrip`; `yearsTable` → `YearTotalsTable`; `kpiTiles` → `KpiTiles`; `diffBadge` / `snapDiff` → `DiffBadge`; `analyticsClosedView` → закрытый год на `/analytics`; `methodNote`, `readOnlyNote` → пометки; `defaultYearId` / `analyticsYear` → `resolveDefaultYear`. Значения закрытых лет в прототипе смоделированы; в приложении — снимки и записи года.

### 5.6 Итоги года на странице группы (`/group`)

Блок «Итоги года · {год}» над составом: четыре итога (`KpiTiles`) с разницей и кнопка «Все годы» → `/analytics`. Год — по умолчанию (контракт §6.5). Данные — из `listGroupYearTotals`.

### 5.7 Отзывчивость смены года

Смена года — прямое действие: экран отвечает в том же кадре, что и клик. Ожидание сервера не оставляет на экране числа предыдущего года так, будто они уже относятся к новому.

Принципы отклика для этих экранов:

1. **Отклик в том же кадре.** Подсветка года, выбранная строка таблицы итогов и пометки «закрытый год» / методологии берутся из строки, которая уже нарисована. Для `/analytics` это `YearTotalsTable`: явка, стихи, тест и тетрадь года меняются вместе со строкой. Не ждать RSC, чтобы сменить эти числа. Сводка периода зависит от фильтра периода и уходит в скелет вместе с графиками.
2. **Чужие числа не остаются текущими.** Графики по урокам, поимённые таблицы и прочие блоки, которых нет в уже загруженной строке года (`/analytics`, `/analytics/pupils/[pupilId]`, `/school`), в том же клике сменяются скелетом и `aria-busy`. Подпись для скринридера — `analytics.years.detail_pending`.
3. **Управление не блокируется.** Кнопки года не получают `disabled` на время загрузки. Новый клик заменяет цель, не дожидаясь предыдущего ответа.
4. **Prefetch не заменяет отклик.** Ссылки лет предзагружаются. Динамическая часть страницы всё равно приходит отдельным ответом, поэтому п. 1–2 обязательны и при тёплом кэше, и без него.
5. **Движение — у нажатия, не у данных.** У кнопки года — `transform` на `:active` и отказ от масштаба при `prefers-reduced-motion`. Смена карточек и графиков — смена состояния, без анимации, которую нужно досмотреть.
6. **Показатель ученика не гасит карточку уроков.** Переключатель `?metric=` по-прежнему меняет столбцы в том же клике (§6.5) и не включает скелет детальной карточки.

| Экран | В том же клике | Скелет, пока грузится RSC |
|-------|----------------|---------------------------|
| `/analytics` | полоса, строка таблицы, `ReadOnlyYearNote`, `MethodologyVersionNote` | фильтр периода остаётся; сводка периода, графики, состав выборки, таблицы учеников, «кто провёл» |
| `/analytics/pupils/[pupilId]` | полоса и таблица «По годам», столбцы показателя | карточка уроков выбранного года (KPI периода, присутствие, графики, динамика, таблица уроков) |
| `/school` | полоса и пометка закрытого года | таблица групп, график посещаемости, «кто провёл» |

## 6. Экран «Аналитика ученика» (`/analytics/pupils/[pupilId]`)

| Блок | Содержание |

### 6.5 «По годам» (v1.2)

| Блок | Содержание | Правило |
|------|------------|---------|
| Полоса лет ученика | кнопки лет, в которые у ребёнка есть строка; выбор пишет `?pupilYear=` | все годы доступного ученика (AZ-49), включая группы до перевода |
| Таблица | год · группа (при переводе внутри года — «Группа 1 → Группа 2») · явка · стихи · тест · тетрадь · «Кирпичики: набрано / выдано» | `lessons < M` → «—» и «мало уроков: k»; «набрано» из снимка, «выдано» вживую; `<caption class="sr-only">` |
| График | столбцы одного показателя по годам; переключатель `явка / стихи / тест / тетрадь` (`seg`, `radiogroup`) | одна ось Y; ось X — годы (заголовок таблицы к графику «Год»); годы с `lessons < M` без столбца, в подсказке «мало данных»; «Показать таблицей»; выбранный показатель и столбцы меняются в том же клике (значения уже в строках), `?metric=` догоняет |
| Примечание учителю | если в строках есть группы другого учителя: «Годы в группах других учителей показаны как строка итогов ребёнка; аналитика этих групп вам недоступна» | `analytics.pupil_years.foreign_group_note`; переходов в чужую группу нет (AZ-50) |

**Раскрытие года:** активный год → существующая карточка §6 (баннер выборки, KPI, присутствие, графики, таблица уроков, динамика, правки). Закрытый год → `ReadOnlyYearNote`, пометка методологии, плитки итогов (явка, стихи, тест, тетрадь, кирпичики «набрано / выдано») и графики по урокам этого года по записям; кнопок «Исправить» нет (teacher), у admin — как в §6 правила AZ-34. Заголовок страницы показывает группы выбранного года.

**Сверка с прототипом:** `pupilYearRows` → `listPupilYearRows`; `pupilYearsSection`; `pupilClosedYear`; `PUPIL_METRICS`.

## 7. Экран «Школа» (`/school`, admin)

Сводка по группам (9.1.2): таблица — ученики A / всего, посещаемость, средние, состояние проверки последнего урока; список «требует внимания». График посещаемости по урокам — **до 3–4 линий** (группы), легенда и подписи у концов; одна ось Y (%). Тот же фильтр периода, что §4.

### 7.1 Школа за выбранный год (v1.2)

Над сводкой — полоса лет (все годы со снимком, `?year=`). Для активного года экран как выше. Для закрытого — `ReadOnlyYearNote`, пометка методологии и таблица групп из снимков: группа · детей в основной выборке · уроков проверено · явка · стихи · тест · тетрадь, у каждой цифры разница с прошлым годом этой группы (порог §5.5); группа, которой в году не было, — строка «В этом году группы не было». Группы сравниваются **только внутри выбранного года**; блок «Требует внимания» не зависит от года. Сверка: `schoolClosedBlock`.

## 8. Методология «Как мы считали» (9.6)

Секция `MethodologyNote` внизу `/analytics` (и краткие строки под графиками): правила БП-1…БП-4, БП-7, «сдано позже», исключение удалённых данных, отсутствие записи = дефект журнала. Тексты — ключи namespace `analytics` в `@/lib/messages` (`analytics.methodology.*`), не дублировать в DAL.

## 10. Happy path

| Сценарий | Исход |
|----------|-------|
| Teacher открывает `/analytics` для своей группы, год по умолчанию | KPI, 4 графика с точками, таблица A, блок уроков по учителям |
| Меняет период на «октябрь» | Все блоки пересчитаны; URL/query или состояние фильтра сохраняет выбор |
| Admin переключает группу | Данные другой группы; teacher видит только свои группы |
| Клик по ученику в таблице A | `/analytics/pupils/[id]` с баннером «учитывается в средних: да» |
| Admin открывает `/school` | Таблица групп и мульти-линейный график посещаемости |
| Пользователь включает «Показать таблицей» у графика | Таблица с теми же числами, доступна с клавиатуры |
| Teacher открывает `/analytics` после закрытия года, нового активного ещё нет (v1.2) | Открыт последний закрытый год, полоса лет без «идёт», пометка «только чтение» |
| Teacher выбирает год в полосе или строкой таблицы | `?year=` меняет KPI, графики, таблицы; закрытый год — из снимка и записей года |
| Teacher видит разницу «на 7 п. п. выше» у явки | Выполнены пороги N / M в обоих годах |
| Teacher открывает карточку переведённого ребёнка | Строки всех лет, у перевода внутри года «Группа 1 → Группа 2»; график по годам; кнопка раскрытия года |
| Admin открывает `/school` в закрытом году | Таблица групп из снимков; разница по группе |
| Teacher нажимает «Все годы» на `/group` | `/analytics` своей группы с таблицей итогов |
