## 1. Purpose

Экраны волны 1 и правило сверки с прототипом. Читают: исполнитель UI-CU P12. Данные и отказы — в контракте; здесь только состав экрана, состояния и обязательное визуальное соответствие.

## 2. Scope / Out of scope

**В scope:** каталог `/achievements`, режим группы, «кого отметить», ручная выдача, отзыв, штраф и снятие, список выдач на карточке ученика, строка бонуса и штрафов в кирпичиках, колонка штрафов в рейтинге. Всё это видно только при `features.achievements = true`.  
**Вне scope:** `/child`, `/family`, дайджест, голос, `practice` как рабочее достижение (в каталоге строка есть и подписана «Ждёт голосовой проверки»).

## 3. Files / area touchpoints

| Поверхность | Маршрут | Функция прототипа | Роль |
|-------------|---------|-------------------|------|
| Каталог | `/achievements` | `vAchievements`, `achDialog`, `penCatDialog` | admin |
| Режим группы | `/group`, карточка группы admin | `achModeCard`, `achModeOffDialog` | teacher своей, admin |
| Кого отметить | `/today` | блок в `vToday` | teacher |
| Выдача и отзыв | диалоги с `/today`, карточки ученика | `awardDialog`, `revokeDialog`, `awardList` в `vPupil` | выдача — teacher/admin; отзыв — admin |
| Штраф | диалог с урока и карточки | `penaltyDialog`, `penOffDialog` | teacher своей в активном году, admin |
| Кирпичики | `/bricks` | строка «в том числе» в `vBricks` | teacher, admin |
| Рейтинг | `/rating` | колонка штрафов в `vRating` | teacher, admin |

Новых маршрутов, кроме `/achievements`, нет. Перенос `/achievements` из §5 в §4 [`canonical_routes.md`](../../../design/canonical_routes.md) — задача P12, когда страница есть. Пункт меню admin «Достижения и штрафы» появляется только при включённом флаге.

Словарь: ключи контракта §7; подписи секций, совпадающие с прототипом, — отдельные ключи `admin.achievements.*` и `teacher.achievements.*` в срезах `admin` и `teacher`.

## 4. Визуальный эталон (обязательно)

Требование владельца 2026-10-22 и [ADR-012](../../../prds/07_governance/adr_012_achievements_and_penalties.md) §4 п. 7. Правило [`ui-prototype-fidelity`](../../../../.cursor/rules/ui-prototype-fidelity.mdc).

Каждый UI-CU сверяет реализацию с названной функцией прототипа и не коммитится, пока расхождений нет. Сверяется:

- структура и порядок секций, кнопок и полей;
- тексты ru дословно, кроме фраз про родителя и дайджест (их в волне 1 нет: подсказка штрафа говорит, что причину видят учитель группы и администратор, без обещания экрана родителя);
- кегль, насыщенность, отступы и радиусы из прототипа и UX-03;
- токены `penalty` / `penalty-soft` для штрафа (флажок и слово «Штраф»), `tier-1`…`tier-3` для бронзы, серебра и золота;
- ширины 390 px, `md` и `lg`.

Красный остаётся за ошибкой и удалением. Отзыв — опасное действие, как `revokeDialog` (кнопка удаления, не цвет штрафа). Новый цвет не вводится. Составной блок сначала появляется в Design Lab (`/design-system`), затем на маршруте. Импорт `@/components/design-lab/**` в маршрутах запрещён.

## 5. Happy path

### 5.1 Каталог

Заголовок «Достижения и штрафы», пояснение про кирпичики, основная кнопка «Достижение», вторичная «Пересчитать достижения», текст про идемпотентность пересчёта. Секции «Постоянство», «Старание», «Память»: название, правило, уровни с точкой уровня и баллами, подпись «Включено» / «Выключено» / «Ждёт голосовой проверки», переключатель. Секция «Штрафы»: флажок `penalty`, баллы со знаком, «действующих: N», кнопка «Штраф». Диалоги `achDialog` и `penCatDialog`: поля и подсказки прототипа, toast успеха 2 с из `@/lib/messages`.

### 5.2 Режим группы

`achModeCard` над сводкой группы. Включение — сразу. Выключение — диалог `achModeOffDialog`, затем период выключения. Подпись состояния текстом рядом с переключателем.

### 5.3 Кого отметить

На `/today` секция «Кого отметить в классе». При включённом режиме — список новых выдач последнего пересчёта (точка уровня, имя, название, уровень, баллы, пометка «вручную») и кнопка «Выдать вручную». При выключенном — текст прототипа и ссылка в настройки группы. Штраф в этот список не входит.

### 5.4 Выдача, список, отзыв

`awardDialog`: ученик, баллы с потолком каталога, достижение и уровень, уроки с предложенными последними подходящими, счётчик «из N», причина. `awardList` на карточке ученика (`vPupil`): название, уровень, «вручную», уроки, баллы; у admin — «Отозвать». `revokeDialog` перечисляет снятие баллов, занятость уроков и окончательность.

### 5.5 Штраф

`penaltyDialog`: ученик, урок, вид, модуль баллов не выше каталога, причина с подсказкой «о поступке». Кнопка «Выдать штраф» — `penalty`. `penOffDialog`: готовые причины и поле «или своими словами»; запись остаётся со статусом «снят».

### 5.6 Кирпичики и рейтинг

В карточке ученика на `/bricks` под тройкой «набрано / выдано / остаток» строка «в том числе бонус +N, штрафы −M» только если слагаемое ненулевое. Штрафы — `text-penalty`. В рейтинге число штрафов — колонка с подписью, не цвет без текста.

### 5.7 Баллы группы

`/group/points` (teacher, активный год) и `/groups/[groupId]/points` (admin, выбор года). Выбор группы и года, таблица «достижение · уровень · условие · общее значение · значение группы». Пустое поле — «как в общем». Отличающаяся строка помечена текстом и иконкой, рядом «Сбросить». Штраф вводится модулем и показывается со знаком «−». Одна кнопка «Сохранить» (pending, toast 2 с), «Скопировать из группы» через подтверждение. Закрытый год у teacher — только чтение с `Banner`. Неактивное `practice` — строкой только для чтения. Ссылка с карточек группы (`/group`, `/groups/[groupId]`). Контракт — [`achievement_group_points_contract.md`](../contracts/achievement_group_points_contract.md).

## 6. Negative paths (UX)

| Случай | Код контракта | UI |
|--------|---------------|----|
| Флаг выключен | `ACHIEVEMENT_FLAG_OFF` | меню и блоки отсутствуют; прямой `/achievements` — 404 |
| Режим выключен, выдача или штраф | `ACHIEVEMENT_MODE_OFF` | toast ошибки; диалог не подтверждает |
| Чужой ученик | `NOT_FOUND` | 404, без различия «нет» и «чужой» |
| Teacher открыл каталог | `FORBIDDEN` | «Нет доступа» |
| Валидация причины, баллов, числа уроков | `VALIDATION` и коды §7 контракта | поле с `border-destructive`, текст ошибки, значения формы сохранены |
| Конфликт пересчёта | `CONFLICT` | toast ошибки, данные не двоятся |
| Пустой каталог секции | — | секция без пустой «ошибки»: список просто пуст, кнопка создания на месте |
| Нет выдач у ученика | — | «Пока нет достижений.» |
| Нет новых выдач сегодня | — | секция «Кого отметить» без элементов списка, кнопка ручной выдачи на месте |

`toast.error` обязателен при отказе мутации. Успех мутации — `toast.success` на 2 с. Кнопка отправки: `disabled`, `aria-busy`, подпись-герундий из словаря.

## 7. Security paths

| Путь | UX |
|------|----|
| Нет сессии | редирект на `/login` |
| Teacher на `/achievements` | forbidden, навигация teacher сохраняется |
| Чужая группа | 404 |
| Отзыв у teacher | кнопки «Отозвать» нет |
| Снятие штрафа teacher в закрытом году | действия нет; admin видит снятие |

## 8. Concurrency notes

Повторная отправка блокируется `disabled` и `aria-busy` на время запроса. Оптимистично переключатель режима не переключается до ответа: отказ возвращает подпись. Пересчёт каталога на время запроса показывает занятость на кнопке «Пересчитать достижения» и не создаёт второй список «кого отметить» из того же ответа.

## 9. UI states matrix

| Область | empty | loading | error | forbidden |
|---------|-------|---------|-------|-----------|
| Каталог | секции без строк, кнопки создания есть | скелет списка | баннер ошибки и повтор | teacher — экран «Нет доступа» |
| Кого отметить | текст и кнопка ручной выдачи | скелет карточки «Сегодня» | баннер, остальная «Сегодня» жива | маршрут teacher-only |
| Список выдач ученика | «Пока нет достижений.» | скелет блока | баннер блока | чужой ученик — 404 страницы |
| Диалог | — | кнопка занята | текст под полями | диалог не открывается |

## 11. Acceptance criteria

- [ ] При выключенном флаге пункта меню и блоков нет, `/achievements` — 404 — исход: ручной проход.
- [ ] Каталог, режим, «кого отметить», диалоги, строка кирпичиков и колонка рейтинга совпадают с функциями §3 на 390 px, `md` и `lg` — исход: `UI-verify: …, расхождений 0` в trace UI-CU.
- [ ] Штраф отличается словом «Штраф» и токеном `penalty`, не только цветом — исход: смотр прототипа и экрана.
- [ ] Ошибка валидации не стирает форму; ошибка мутации даёт toast — исход: ручной отказ (баллы выше каталога).
- [ ] Teacher не видит отзыв и каталог — исход: проход под teacher.
