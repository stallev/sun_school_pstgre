## Purpose

1. Сделать приём «слово + значок «?» + пояснение» стандартом интерфейса: у каждого термина предметной области, вычисляемой цифры и необратимой кнопки (приоритет A каталога ниже) есть подсказка.
2. Закрыть видимый регресс: в «Кирпичиках» у значка нет подписи «К выдаче» (D-1). Сделать невозможным повтор: компонент `TermLabel` всегда выводит слово.
3. Довести журнал, списки людей, заявки, достижения, настройки и аналитику по дефектам D-2…D-22 из третьего аудита.

## Scope / Out of scope

### In scope

- Компонент подсказки (`TermLabel`, `TermHeader`, вариант `reason`), словарь `hints.*` (ru и en) по срезам, подсказки на всех экранах приоритета A каталога.

- Права и `route-table.ts`; схема БД, миграции; инфраструктура Neon; расчёты аналитики; новые маршруты; страница «Справка»; мобильный прогон 390 px и английская локаль (отдельный проход после P27); чистка тестовых данных стенда («Фикстура …»).

## Черновики текстов (Q-1 ADR-020, правит владелец при ревью)

| Ключ | Подпись | Текст подсказки |
|------|---------|-----------------|
| `t.regular_attendance` | Регулярно ходят | Дети, которые были не менее чем на половине проверенных уроков. Средние считаются только по ним |
| `t.attendance_rate` | Посещаемость | Доля присутствовавших среди регулярно ходящих детей на проверенных уроках года |
| `t.average_score` | Средний балл | Среднее число баллов за урок: стихи, тест, тетрадь. Считается по регулярно ходящим |
| `t.checked_state` | Проверено | Ученик проверен, когда заполнены все поля. «Частично» — заполнена часть |
| `t.lesson_type` | Тип урока | Обычный: стихи, тест, тетрадь. Обзорный: повторение, без стихов и теста, в среднее по стихам не входит |
| `t.score_threshold` | до 4 / от 8 | Красное «до 4» — слабый результат, на него стоит обратить внимание. «От 8» — порог для достижения «Аккуратная тетрадь» |
| `t.verse_scale` | Оценка за стих | 2 — рассказал без подсказки, 1 — с подсказкой, 0 — не смог. «Не отвечал» — не вызывался, баллы не начисляются |
| `t.check_status` | Статус проверки | Проверен — все поля заполнены. Частично — часть полей пуста. Не проверен — ничего не заполнено |
| `t.bricks_collected` | Набрано | Баллы уроков плюс бонус за достижения минус штрафы за год |
| `t.bricks_issued` | Выдано | Сколько кирпичиков уже отдано ученику |
| `t.bricks_left` | Остаток | Сколько ещё можно выдать: набрано минус выдано |
| `t.bricks_issue` | Выдать | Записывает выдачу в журнал. Ошибку можно исправить новой записью, удалить нельзя |
| `n.record_without_mark` | Нет отметки | Запись — это ученик на уроке. «Нет отметки» — урок проверен, а оценка не поставлена. Откройте журнал уроков и дополните |
| `n.low_score` | Низкий балл | Средний балл за тест или тетрадь ниже порога. Нужно внимание учителя |
| `n.not_in_average` | Не входят в средние | Дети с явкой ниже 50% не меняют средние группы. Их личные цифры видны в карточке ученика |
| `a.audit_system` | Системные записи | Автоматические действия: загрузка перевода Библии, установка пароля. Люди их не совершали |
| `a.audit_entity_type` | Тип объекта | То, над чем сделано действие: ученик, урок, заявка, достижение |
| `a.consent_migrated` | Без согласия (перенесённые) | Ученики из старого приложения, у которых нет подтверждения согласия на обработку данных. Нужно получить согласие |
| `a.pupil_transfer` | Перевести | Переводит ученика в другую группу. История оценок остаётся |
| `a.approval_roles` | Роли | Администратор управляет школой. Учитель ведёт свои группы: уроки, проверка ДЗ, кирпичики |
| `a.user_statuses` | Статусы | Регистрация — вошёл, но не отправил заявку. Ожидает решения — заявка отправлена. Активен — роль выдана |
| `a.deletion_anonymize` | Обезличим | Имя заменяется на «Удалённый ученик»; записи остаются в истории школы |
| `a.family_login` | Вход семьи | «Входит» — родитель может заходить в приложение. «Без аккаунта» — нет, только контакт |
| `a.year_close` | Закрыть год | Для учителей данные года станут только для чтения. Закрытие нельзя отменить |
| `a.timezone` | Часовой пояс | Влияет на время уроков и записей. Прошлые записи не пересчитываются |
| `a.link_logins` | Способы входа | Привяжите Telegram и email: тогда войти можно любым. Иначе появятся два разных пользователя |
| `a.ach_cumulative` | Накопительно | Считаются все подходящие уроки подряд и не подряд |
| `a.ach_series` | Серия | Подходящие уроки идут подряд; пропуск обрывает серию |
| `a.ach_recalc` | Пересчитать достижения | Нужно после правок задним числом. Дублей не создаёт |

## Happy path smoke

1. `/bricks`: над таблицей видно «К выдаче» + «?» + «: 1057»; в заголовках «Набрано / Выдано / Остаток» есть «?».
2. `/check`: у «до 4», «от 8», шкалы и статусов есть «?»; popover заголовков таблицы открывается вверх.
3. `/audit`: нет UUID и JSON вне «Технической записи»; «Заявка на доступ» один раз; «Система» один раз.
4. `/settings`: все пояса по-русски; поиск «Нью» находит «Нью-Йорк, США».
5. `/achievements`: «после 1 урока», «после 5 уроков», «+1 кирпичик», «+5 кирпичиков»; «Сто кирпичиков» — «после 100 баллов».
6. Меню «Смотреть как → Учитель»: нажатие на «Состав группы» показывает причину.

## Negative path smoke

1. Ключ подсказки отсутствует в словаре — тест падает, пустого значка в UI нет.
2. Подсказка у правого края окна и в таблице раскрывается влево/вверх и не уходит за экран; Esc закрывает; открытие второй закрывает первую.
3. Пустая подпись у `TermLabel` — ошибка типов/теста.
4. Тёзки в `/users` различаются (email или роль).
5. Дата «Подана вчера» корректна около полуночи в поясе школы.
6. Неизвестный `*Id` в журнале не показывается в основной строке.

## Security smoke

1. `/audit`, `/users`, `/people`, `/deletions`, `/approvals`, `/family` — по-прежнему только admin; teacher получает отказ.
2. Подсказки не раскрывают данных других пользователей; в «Технической записи» — только admin.
3. Email в списке тёзок виден только admin.
4. Права и `route-table.ts` не менялись (grep по diff).

## Concurrency & race check

- Один открытый popover на странице (`dismissOtherHints`); быстрый повторный клик не оставляет два открытых.
- Журнал и списки читаются на сервере; подсказки — чистые строки, состояние только `open` (client).

## Drift risks & guards

| Риск | Страж |
|------|-------|
| Значок без слова снова (D-1) | тест `TermLabel` выводит `term`; ESLint-запрет импорта `TermHint` на экранах (CU1) |
| Ключ подсказки без перевода | тест паритета ru/en и покрытия каталога (CU2) |
| Слово предметной области без подсказки | чек-лист review; список `forbidden-terms` + список «терминов с подсказкой» (CU2) |
| UUID/JSON вне «Технической записи» | тест рендера журнала (CU5) |
| Латиница в списке поясов | тест списка (CU7) |
| Неправильные склонения | тест `plural` для достижений (CU8) |
