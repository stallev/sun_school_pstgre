# G1 Вход

## Среда

Деплой: https://dev-sun-school-pstgre.vercel.app (вкладка viewId 89f2f0). Эталон: `docs/prototypes/sunday_school_prototype.html`, экран `login` (ключ прототипа). Ширины 390, 768, 1024. Горизонтальная прокрутка: `document.documentElement.scrollWidth > clientWidth`.

## /login

Одинаковая вёрстка на 390, 768 и 1024: колонка по центру, одна залитая кнопка «Войти через Telegram», контурная «Войти» только после раскрытия. Горизонтальной прокрутки нет. Оверлея ошибки на экране нет; сообщения консоли снять не удалось.

Совпало с прототипом на всех ширинах: одна главная кнопка «Войти через Telegram»; подписи «Email», «Пароль», «Войти», «Скрыть», разделитель «или»; email-поля скрыты, пока не нажата подпись раскрытия.

Не совпало (на всех ширинах одинаково):

- Бренд «Sunday School» вместо «Воскресная школа».
- Заголовок «Вход в приложение» и подзаголовок «Войдите через Telegram или по email и паролю.» вместо «Вход для учителей и родителей» и «Подтвердите вход в Telegram — пароль не нужен.»
- Между подзаголовком и кнопкой Telegram стоит строка «Тестовое окружение» — в макете её нет.
- Пояснение «Учётную запись с паролем создаёт оператор.» и подпись «Вход по email» вместо «Пароль нужен только администратору.» и «Вход для администратора».
- В раскрытом блоке заголовок «Вход по email» вместо «Вход для администратора».
- Внизу ссылка «Согласие на обработку данных»; в макете входа её нет. Строка прототипа про несвязанные кнопки на деплое не ожидается.

## /privacy

Экрана прототипа нет, расхождение с макетом не ставится. Страница открывается: https://dev-sun-school-pstgre.vercel.app/privacy. Заголовок документа: Privacy. Заголовок на странице: «Согласие на обработку персональных данных». Горизонтальной прокрутки нет на 390, 768 и 1024. Оверлея ошибки нет; сообщения консоли снять не удалось. После проверки возврат на `/today`, оболочка учителя на месте.
