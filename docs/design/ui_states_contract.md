## 1. Purpose

Сделать состояния **loading, empty, error, forbidden** равноправными частями каждого экрана: не «потом», а в первой версии. Читают: авторы specs W9, исполнители UI-фаз, `reviewer`.

## 2. Scope / Out of scope

**В scope:** состояния маршрутов `(app)` и `(auth)`, региональные состояния, домен-специфичные состояния.  
**Вне scope:** тексты (словари, ADR-008), анимации и визуальные токены ([`visual_identity_contract.md`](./visual_identity_contract.md)), поведение форм ([`forms_and_validation_ux.md`](./forms_and_validation_ux.md)), pending кнопок мутаций (`ui-mutation-pending`).

## 3. Definitions

| Термин | Значение |
|--------|----------|
| Route loading | Ожидание данных маршрута: `loading.tsx` / Suspense |
| Mutation pending | Ожидание ответа мутации: `disabled` + `aria-busy` на контроле; **не** skeleton страницы |
| Empty | Данных нет **штатно** (первое использование, фильтр без результатов) |
| Error | Неожиданный сбой или отказ операции с кодом домена |
| Forbidden | Доступ не разрешён: роль (403), чужой / отсутствующий ресурс (404), статус (перенаправление) |
| Key | Ключ словаря (`common.states.*`, ADR-008); текст в этом документе — только пример |

## 4. Правила состояний

### S1 — Loading

| ID | Правило |
|----|---------|
| S1.1 | Маршрут с данными имеет `loading.tsx` (страховка навигации) и `<Suspense>` вокруг **независимых** регионов; оболочка (header, навигация) показывается сразу |
| S1.2 | Skeleton повторяет геометрию контента: без сдвига макета (CLS); высота списка — по ожидаемому числу строк, не по пустой |
| S1.3 | Skeleton не показывается дольше нужного: короткие загрузки не мигают заглушкой (порог — деталь реализации, не контракт) |
| S1.4 | Контейнер региона: `aria-busy="true"` пока идёт загрузка; для длинных — видимая или скрытая подпись `role="status"` |
| S1.5 | Loading **не** используется для ожидания мутации (кнопка отправляется со своим busy-состоянием) |
| S1.6 | Частичные данные допустимы: уроки видны, пока загружается аналитика |

### S2 — Empty

| ID | Правило |
|----|---------|
| S2.1 | Пустое состояние содержит: короткое объяснение **что здесь будет**, и **одно** основное действие (если роль может его выполнить) — Zero Dead Ends (FX-8) |
| S2.2 | Если роль действие выполнить **не может** — объяснение, кто может («Попросите администратора…»), без кнопки |
| S2.3 | Пусто из-за фильтра отличается от «данных нет вообще»: показывается «Ничего не найдено» и действие «Сбросить фильтр» |
| S2.4 | Пустое состояние визуально спокойное: иконка `muted`, без `danger`, без анимаций |
| S2.5 | Нулевое **значение** (0 баллов) и **отсутствие** оценки («не оценивалось») показываются по-разному (INV-11): «0» и «—» |

### S3 — Error

| ID | Правило |
|----|---------|
| S3.1 | Сбой загрузки сегмента → `error.tsx` рядом с данными (не только корневой), кнопка «Повторить» (`retry()`), ссылка «На главную» |
| S3.2 | Сбой независимого региона → региональная граница (`catchError`): остальная страница работает |
| S3.3 | Сообщение — по ключу от кода домена; технические детали, стек, SQL, токены **не показываются**; в UI допустим `digest` для обращения |
| S3.4 | Серверные сбои уходят в Sentry (в событии — `digest`, маршрут, роль; без ПД и без значений форм) |
| S3.5 | Ошибка **мутации** показывается на месте (под полем / в блоке формы) и дублируется `toast.error`; данные формы не теряются |
| S3.6 | Корневой layout: `global-error.tsx` со своими `<html>` / `<body>` и минимальным стилем, без зависимости от словарей |
| S3.7 | Недоступность БД / внешнего провайдера входа — восстановимое сообщение и повтор, не «белый экран» |

### S4 — Forbidden

| ID | Ситуация | Поведение |
|----|----------|-----------|
| S4.1 | Нет сессии | → `/login` (AZ-D1); после входа — возврат на запрошенный путь из `canonical_routes` |
| S4.2 | Статус не допускает маршрут | → домашний маршрут статуса (authorization_matrix §6); без сообщения об ошибке |
| S4.3 | Роль не подходит (teacher на `/users`) | Экран «Нет доступа» (403) внутри оболочки роли, кнопка «На главную» (AZ-D3) |
| S4.4 | Чужой или несуществующий ресурс | `not-found` (404), без различия причин (AZ-D4) |
| S4.5 | Сессия истекла / пользователь отключён | → `/login`, сообщение `auth.login.denied` или «Войдите снова» (auth_runtime_spec §8) |
| S4.6 | Мутация вне прав | Отказ `FORBIDDEN`, toast, страница не перезагружается (AZ-D5) |
| S4.7 | Раздел выключен флагом (`features.*`) | Маршрута нет (404); пункт меню не рендерится |

Скрытие элемента — удобство, не защита: проверка на сервере остаётся (authorization_matrix §4).

## 5. Домен-специфичные состояния

| ID | Состояние | Где проявляется | Поведение |
|----|-----------|-----------------|-----------|
| D1 | Нет активного учебного года | любой экран teacher; `/school`, `/groups`, `/year` у admin | Teacher: «Учебный год ещё не начат», без действий. Admin: призыв «Создать учебный год» → `/year` |
| D2 | Teacher без назначения в активном году (AZ-P6) | `/today`, `/lessons`, `/group`, `/bricks`, `/rating`, `/analytics` | «Вас пока не назначили на группу — обратитесь к администратору» |
| D3 | Год закрыт | экраны teacher с данными прошлого года | Баннер «Год закрыт — только чтение»; кнопки изменения **не рендерятся** (проверка и на сервере, AZ-P5); admin видит действие с обязательной причиной |
| D4 | Урок обзорный | карточка урока, проверка | Блоки «стихи» и «тест» не показываются; не как «пусто» |
| D5 | Проверка урока не начата / частично | `/lessons/[id]`, `/today`, `/check` (нет текущего урока) | «Проверено N из M»; продолжить с первого непроверенного; не проверенный ≠ 0; `/check` без текущего урока — пустое состояние с выбором урока (flow spec §4) |
| D6 | У ученика нет оценки | таблицы, аналитика | «—», в среднее не входит (INV-11) |
| D7 | Оценка «сдано позже» | таблица, карточка ученика | Метка рядом со значением; цвет не единственный признак |
| D8 | Баланс кирпичиков отрицателен | `/bricks` (teacher, admin) | «Требует внимания», видно только teacher/admin (INV-18) |
| D8a | Нет набранных баллов за год | `/bricks` | Пустое состояние «Баллов пока нет» (`bricks.empty_earned_*`); выдача недоступна |
| D9 | Язык группы `EN`, перевод не `READY` (ЯГ-3) | `/groups/[id]`, выбор стихов | Пункт `EN` недоступен с объяснением; существующая группа — предупреждение admin |
| D10 | Нет текста стиха в переводе группы (R-9, ПБ-5) | форма урока | Урок не сохраняется; список недостающих стихов; не «ошибка сервера» |
| D11 | Ученик неактивен / без группы | `/people`, `/group` | Отдельная метка и раздел; не смешивается с зачисленными |
| D12 | Недостаточно данных для графика | `/analytics*` | Текст «Пока мало данных» + что нужно (N уроков); график не рисуется |
| D13 | Пояс школы не выбран (ADR-004) | `/school`, `/settings` у admin | Предупреждение с действием «Выбрать часовой пояс»; работа не блокируется |
| D14 | Неотправленные изменения проверки | `/lessons/[id]/check` | Индикатор «Есть несохранённые изменения»; предупреждение при уходе |
| D15 | Заявка ждёт / отклонена | `/pending` | Статус, дата, причина отказа (если есть), «Исправить и отправить снова», «Выйти» |

## 6. Матрица «тип экрана × состояние»

`●` — обязательно в первой версии; `○` — по условию.

| Тип экрана | Loading | Empty | Error | Forbidden | Особенности |
|------------|:-------:|:-----:|:-----:|:---------:|-------------|
| Дашборд (`/today`, `/school`) | ● | ● (D1, D2, D5) | ● | ● | Регионы независимы: прогресс, ближайший урок, качество данных |
| Список (уроки, пользователи, заявки, удаления, журнал, ученики) | ● | ● (S2.3) | ● | ● | Пагинация / «Показать ещё»; пустой фильтр ≠ пустой список |
| Деталь (урок, ученик, пользователь, группа) | ● | ○ | ● | ● (404 для чужого) | Заголовок виден до данных |
| Проверка ДЗ (`/lessons/[id]/check`) | ● | ○ (нет учеников в группе) | ● | ● | D3, D5, D6, D14; сохранение по ученику — pending на кнопке |
| Таблица урока (`/lessons/[id]/table`) | ● | ● | ● | ● | Горизонтальная прокрутка с фиксированным именем, D6, D7 |
| Аналитика, рейтинг | ● | ● (D12) | ● | ● | Таблица-альтернатива графику (a11y) |
| Календарь | ● | ● | ● | ● | Пустой месяц — призыв «Добавить событие» (для роли с правом) |
| Форма (создание / правка) | ○ | — | ● (S3.5) | ● | Поведение — [`forms_and_validation_ux.md`](./forms_and_validation_ux.md) |
| Диалог подтверждения | — | — | ● (в диалоге) | — | Ошибка остаётся в диалоге |
| Auth (`/login`, `/register`, `/pending`, `/privacy`) | ○ | — | ● (ошибки входа) | ● (перенаправления) | Нет оболочки; всегда есть путь вперёд или «Выйти» |

## 7. Чек-лист «маршрут × состояние»

Список маршрутов — [`canonical_routes.md`](./canonical_routes.md) §4. Для **каждой** строки раздела спецификации экрана (W9) указывается, как реализованы loading / empty / error / forbidden; отсутствие — blocker review. Минимум по группам:

| Группа | Loading | Empty (ключевой случай) | Error | Forbidden |
|--------|---------|-------------------------|-------|-----------|
| `(auth)` | — | — | ошибки входа (auth_runtime_spec §8) | перенаправления по статусу |
| Общие `(app)` (`/profile`, `/calendar`, `/rating`, `/verses`, `/analytics*`, `/bricks`) | `loading.tsx` | нет событий / данных / баланса | `error.tsx` | 403 / 404 |
| Teacher | `loading.tsx` | D1, D2, нет уроков, нет учеников | `error.tsx` | 403 для admin-маршрутов |
| Admin | `loading.tsx` | нет заявок, нет запросов на удаление, нет групп | `error.tsx` | 403 для teacher |

## 8. Paths (H / N / S)

| Путь | Описание | Исход |
|------|----------|-------|
| **H** | Admin открывает `/approvals`, заявок нет | Пустое состояние «Новых заявок нет» без кнопки (действия нет) |
| **H** | Teacher открывает `/lessons`, уроков нет, год активен | Пусто с кнопкой «Создать урок» |
| **N** | Teacher открывает `/today`, года нет | D1: пояснение, без действия |
| **N** | Страница уроков упала (БД) | `error.tsx`: «Не удалось загрузить», «Повторить», оболочка цела |
| **N** | Медленная аналитика | Остальная страница интерактивна; регион — skeleton |
| **S** | Teacher вводит `/lessons/<чужой-id>` | 404 без раскрытия существования |
| **S** | Сообщение ошибки не содержит ПД и stack | Проверка `error.tsx`: показывается ключ и `digest` |
| **a11y** | Скринридер | Пустые и ошибочные регионы объявляются (`role="status"` / `role="alert"`); фокус при ошибке — на заголовок состояния |

## 9. Acceptance criteria

- [ ] Каждый маршрут `canonical_routes.md` §4 имеет описанные S1–S4 в своей спецификации — исход: чек-лист §7 без пустых ячеек.
- [ ] Пустые состояния имеют действие либо объяснение, кто может действовать — исход: ручной просмотр, нет «тупиков».
- [ ] Ошибка не показывает stack, SQL, токены — исход: проверка production-сборки.
- [ ] Значения `0` и «—» различаются в таблицах и аналитике — исход: тест рендера (INV-11).
- [ ] Закрытый год не показывает кнопки изменения teacher — исход: тест policy + UI (AZ-P5).
- [ ] Skeleton не вызывает CLS на 390 px — исход: ручная проверка.

## 12. Agent notes

- Не показывать пустой экран без объяснения и пути дальше.
- Не использовать skeleton вместо pending кнопки и наоборот.
- Не выводить текст ошибки сервера пользователю; только ключ по коду домена.
- Не скрывать недоступное действие без серверной проверки.
- Не добавлять `middleware.ts`; перенаправления — `proxy.ts` по [ADR-002](../prds/07_governance/adr_002_nextjs_vercel_runtime_policy.md).
