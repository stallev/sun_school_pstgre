## 1. Purpose

Описать, что делает учитель в MVP: вход, уроки, проверка ДЗ, кирпичики, аналитика своей группы. Читают: авторы specs, contracts и задач. Права — канон в `authorization_matrix` (W5-02).

## 2. Scope / Out of scope

**В scope:** регистрация и ожидание заявки, «Сегодня», уроки и золотые стихи, проверка ДЗ и корректировка, кирпичики, группа, календарь, рейтинг, аналитика, профиль и запрос на удаление своей учётной записи.  
**В scope дополнительно с P12** (флаг `features.achievements`, [ADR-012](../../../07_governance/adr_012_achievements_and_penalties.md)): режим группы, «кого отметить», ручная выдача, штраф и снятие в своей группе.  
**Вне scope (post-MVP):** голосовая проверка, родители и семьи, каталог и отзыв (только admin).

## 3. Definitions

Статусы записи проверки, тип урока (обычный / обзорный), оценки 0–2 — enum-ы `@sunschool/domain` (источник — [`database_schema_v1.md`](../../../03_data_model/database_schema_v1.md) ). Правила — спец. §3.10–3.12, БП-1…БП-4, БП-10…БП-12.

## 4. Flows

### 4.1 Регистрация и ожидание (РГ-1…РГ-4)

| Шаг | Действие | Исход |
|-----|----------|-------|
| 1 | Входит через Telegram (scope `openid`, в приложении сохраняется только id Telegram). В dev после `db:seed:teacher` можно войти по email и паролю — учётка уже `ACTIVE`, согласие записано, открывается `/today` | Статус «Регистрация» для Telegram; любой адрес ведёт на регистрацию |
| 2 | Заполняет ФИО (фамилия, имя обязательны), отмечает согласие на обработку ПД | Кнопка «Отправить» активна только при согласии |
| 3 | Отправляет | Статус «Заявка на рассмотрении»; экран ожидания |
| 4 | Admin одобряет | Статус «Активна»; открываются разделы teacher |

*Negative:* заявка отклонена — виден текст причины, можно исправить профиль и отправить повторно; новая версия согласия блокирует работу до принятия (РГ-5).

### 4.2 «Сегодня» и урок

| Шаг | Действие | Исход |
|-----|----------|-------|
| 1 | Открывает «Сегодня» | Незавершённая проверка (прогресс «N из M»), кнопки «Продолжить проверку», «Новый урок» |
| 2 | «Новый урок»: дата, тип (обычный / обзорный), ведущий учитель, золотые стихи (диапазоны), признак теста | Урок создан в активном году |

*Negative:* нет активного года — создавать урок нельзя (БП-6); золотой стих нельзя собрать в переводе группы — форма показывает недостающие стихи (ПБ-5).

### 4.3 Проверка ДЗ (3.12, БП-1…БП-4)

| Шаг | Действие | Исход |
|-----|----------|-------|
| 1 | «Проверка ДЗ» → текущий урок | Список учеников, проверка по очереди |
| 2 | По ученику: присутствие, стихи 0–2 (по стихам предыдущего урока, БП-2), тест, тетрадь, спевка, комментарий | Запись сохранена |
| 3 | «Завершить» | Сводная таблица урока; урок считается проверенным |

*Negative:* «не оценивалось» ≠ 0 (БП-4); ученик без записи — дефект журнала (счётчик качества данных).

### 4.4 Корректировка проверенного урока (БП-12)

1. В сводной таблице открывает запись ученика.
2. Меняет оценку, присутствие, комментарий; ставит «сдано позже».
3. Результат: оценка относится к дате урока; дата сдачи хранится отдельно; запись в журнале.

*Negative:* год закрыт — править может только admin с причиной; присутствие задним числом из-за поздней сдачи не меняется.

### 4.5 Кирпичики (БП-11)

| Шаг | Действие | Исход |
|-----|----------|-------|
| 1 | «Кирпичики» → ученик → баланс «набрано / выдано / остаток» | Видит остаток |
| 2 | Выдаёт N кирпичиков | Запись в журнале (только добавление) |
| 3 | Ошибка — компенсирующая запись с примечанием | Остаток исправлен, история сохранена |

*Negative:* выдать больше остатка нельзя; количество — положительное целое.

### 4.6 Моя группа, календарь, рейтинг, аналитика

| Раздел | Действие | Исход |
|--------|----------|-------|
| «Моя группа» | Состав; пакетное добавление / удаление учеников | Изменение с записью в журнале |
| «Календарь» | События группы: создание, правка, удаление | Видны группе |
| «Рейтинг» | Просмотр своей группы | Рейтинг по правилам §8 |
| «Аналитика» | Группа, ученик, «кто какие уроки провёл»; **выбор учебного года** среди годов своего назначения, итоги по годам, разница с прошлым годом; у ученика — «По годам» (все годы, включая группы до перевода); на «Моей группе» — «Итоги года» и «Все годы» | Средние по БП-1, строка качества данных; закрытый год — только чтение; «мало данных для сравнения» при малой выборке; после закрытия года открывается последний закрытый год ([`multi_year_analytics.md`](../../multi_year_analytics.md)) |
| «Профиль» | Просмотр; запрос на удаление своей учётной записи (УД-1) | Запрос «Новый»; можно отменить |
| «Сегодня», «Моя группа» | При включённом флаге: список «кого отметить», режим достижений группы, ручная выдача и штраф | При выключенном режиме список объясняет, что награды не считаются; каталог и отзыв teacher недоступны ([`achievements_screens_spec.md`](../../../../implementation/mvp/specs/achievements_screens_spec.md)) |

## 5. Security paths (ссылки)

Teacher видит и правит только **свои** группы; чужая группа или чужой ученик → 404 / 403. Закрытый год — только чтение. Детали: [`authorization_matrix`](../../../04_authorization_privacy/authorization_matrix.md), [`homework_check_contract`](../../../../implementation/mvp/contracts/homework_check_contract.md), [`bricks_ledger_contract`](../../../../implementation/mvp/contracts/bricks_ledger_contract.md).

## 9. Agent notes

- Золотые стихи берутся из стихов предыдущего **обычного** урока (БП-2); обзорный урок пропускается.
- Присутствие не влияет на баллы (БП-10), только на посещаемость.
