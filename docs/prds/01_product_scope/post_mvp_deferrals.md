## 1. Purpose

Зафиксировать, что отложено, в каком порядке и при каких условиях входит. Нужен, чтобы агенты не реализовывали post-MVP заготовками и знали, что в схеме уже есть таблицы под эти волны.

## 2. Scope / Out of scope

**В scope:** три волны post-MVP, зависимости, условия старта, что уже заложено в схеме и в прототипе.  
**Вне scope:** проектирование самих волн (отдельные спецификации при старте волны).

## 3. Волны

Порядок — по зависимостям и риску. Каждая волна начинается, когда предыдущая работает у реальных пользователей.

### 3.1 Волна 1 — достижения и штрафы

| Что | Источник |
|-----|----------|
| Каталог достижений и штрафов | `achievements_spec.md` §2, §6 |
| Автоматический пересчёт по событию «проверка завершена» с доказательствами | ДС-3, ДС-6, ДС-11, ДС-12 |
| Ручная выдача, отзыв | ДС-5, ДС-7, ДС-13 |
| Режим «Достижения и штрафы» группы | ДС-14 |
| Штрафы: выдача, снятие | ШТ-1…ШТ-10 |
| Бонус и штрафы в «набрано» кирпичиков | БП-11, ДС-10 |
| Перенесённые выдачи становятся видны | Раздел 13 спецификации |

**Условие старта:** MVP работает у реальных пользователей; алгоритм пересчёта покрыт тестами чистой функции (`achievements_spec.md` §7.3).

### 3.2 Волна 2 — семьи и родители

| Что | Источник |
|-----|----------|
| Семьи, взрослые, правила СМ-1…СМ-10 | спец. §2.3, §3.9 |
| Роль `parent` при одобрении заявки | спец. §2.4 |
| Электронное согласие на данные ребёнка; отзыв = запрос на удаление | СО-1, СО-2, СО-6 |
| Экраны родителя | §9.2, БП-9 |

**Условие старта:** собраны бумажные согласия на данные детей; внесены семьи (в старом приложении семей нет — вносятся с нуля).

### 3.3 Волна 3 — голосовая проверка стихов (AI)

| Что | Источник |
|-----|----------|
| Gate: тест распознавания на 30–50 записях | спец. §6.2 |
| Согласие родителя на запись голоса | ВП-15, §3.17 |
| Запись попытки, оценка, обратная связь | §6.3–6.5, ВП-1…ВП-14 |
| Правило «N дней» и окно практики | ВП-8 |
| Метрики качества AI-оценки | §9.3 |

**Условие старта:** работает волна 2 **и** пройден gate §6.2. Если распознавание детской речи не проходит gate — волна сводится к «ребёнок записывает, учитель слушает».

## 5. Paths (H / N / S)

| Путь | Описание | Исход |
|------|----------|-------|
| **H** | Волна стартует по условию §3 | Реализация по отдельной спецификации и ADR |
| **N** | Агент включает post-MVP заготовку в MVP-задачу | Отклоняется на DoR / review |
| **S** | Данные детей и голос появляются в волне 2–3 | Требуют согласий (СО, ВП-15) до включения флага |

## 6. Acceptance criteria

- [ ] Каждая волна имеет условие старта — исход: строка «Условие старта» в §3.
- [ ] Все post-MVP экраны `canonical_routes.md` §5 попадают в одну из волн — исход: нет экрана без волны.
